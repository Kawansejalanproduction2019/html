Keamanan Komunitas

Moderasi & Sentinel Defense

cogs/moderation.py • 20 Perintah

Sistem pertahanan server komprehensif dengan dasbor interaktif, audit log otomatis, proteksi tautan phishing berbasis analisis AI, honeypot otomatis, dan hierarki peran ketat.

Master Control Center (/setup) Wizard pengaturan terpadu Auto Role, Verification, Welcome Card, Audit Log, dan Ticket System tanpa reload bot.
Live Moderation Panel (/modpanel) Papan pantau aktif real-time yang menampilkan Voice Pulse, statistik member timeout, dan tombol tindakan cepat.
Honeypot Trap Channel (/trap) Kanal jebakan otomatis yang langsung mendeteksi bot raid atau spammer lalu menjatuhkan timeout 28 hari.
AI Cyber Defense (/cyber_toggle) Penyaring kata terlarang dan pemindai tautan mencurigakan berbasis evaluasi model bahasa Gemini.

Radar & Notifikasi Multi-Platform

cogs/notif.py • 6 Perintah Pemilik

Deteksi otomatis siaran langsung (Live Streaming), video baru, dan feed reels dari YouTube, TikTok, dan Instagram secara real-time dengan anti-duplikasi cache.

Deteksi Tri-Platform Mendukung deteksi URL otomatis YouTube (Video, Shorts, Live), TikTok (Video, Live), dan Instagram (Reel, Post).

!resetcache Prefix • Owner Bersihkan antrean cache konten media untuk kebutuhan verifikasi kirim ulang notifikasi.

Infrastruktur & Basis Data

Cloud Backup & Sinkronisasi Repositori

main.py • 3 Perintah Administrator

Arsitektur ketahanan data ganda: pencadangan otomatis dokumen JSON ke MongoDB Atlas, sinkronisasi file ke repositori GitHub via API, serta pengiriman arsip ZIP berkas cog ke webhook rahasia.

Pencadangan Ganda MongoDB & GitHub Perintah !backupnow memindai file konfigurasi lokal, mengunggah ke GitHub branch utama, dan menyimpan snapshot di MongoDB.
Arsip ZIP via Webhook (!sendbackup) Mengompres seluruh basis data JSON ke arsip terenkripsi ZIP dan mengirimkannya ke webhook log Discord pemilik bot.
Cadangan Kode Individual (!cogbackup) Antarmuka dropdown interaktif untuk memilih dan mencadangkan skrip modul Python (.py) spesifik ke webhook.
Remote Command Queue Mekanisme pemrosesan antrean perintah web berbasis MongoDB collection untuk mengeksekusi aksi bot secara jarak jauh.
Perintah Tipe & Akses Deskripsi Fungsional Salin
!backupnow Prefix • Owner Inisiasi pencadangan instan seluruh file konfigurasi JSON ke MongoDB dan GitHub.
!sendbackup Prefix • Owner Kirimkan salinan arsip data terbaru berformat file ZIP ke webhook log cadangan.
!cogbackup Prefix • Owner Buka menu interaktif untuk mencadangkan kode modul Python individual (.py) ke webhook.
/sync [scope] Hybrid • Owner Sinkronisasikan seluruh pohon perintah slash ke Discord API (instan per guild atau global).
