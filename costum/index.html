Moderasi & Sentinel Defense

20 Perintah

Master Setup (/setup), Live Modpanel (/modpanel), Honeypot Trap (/trap), AI Anti-Phishing Filter, dan pembersihan pesan massal.

Perintah Tipe Fungsi Aksi
/setup Hybrid • Admin Master Server Setup: Auto-Role, Log, Booster, Welcome Message, & Ticket.
/modpanel Hybrid • Mod Dasbor moderasi real-time dengan status Voice Pulse dan aksi cepat moderator.
/panelrole Hybrid • Admin Buat panel ambil role mandiri menggunakan tombol interaktif atau menu dropdown.
/ticket Hybrid • Admin Sistem tiket bantuan komunitas dengan kanal privat dan log transkrip.
/trap Hybrid • Admin Aktifkan kanal honeypot untuk mendeteksi spammer dan auto-timeout 28 hari.
/clear <jumlah> Hybrid • Mod Hapus pesan massal di kanal teks atau suara hingga 100 pesan sekaligus.
/ban <member> Hybrid • Ban Perms Blokir permanen pengguna dari server dengan proteksi hierarki peran otomatis.

Tanya Jawab

Pertanyaan Seputar Pembuatan Bot

Jawaban jujur seputar hosting, kepemilikan kode, dan pemeliharaan server bot.

Berapa lama pengerjaan bot custom?
Untuk bot komunitas standar rata-rata selesai dalam 2 hingga 4 hari kerja. Untuk proyek custom yang membutuhkan integrasi khusus memakan waktu sekitar 5 hingga 8 hari kerja.
Apakah saya harus sewa VPS atau server sendiri?
Tidak perlu. Kami sediakan infrastruktur cloud hosting aktif 24 jam. Namun jika kamu punya VPS sendiri dan ingin self-host, kami bantu setupkan sampai tuntas.
Apakah nama dan avatar bot bisa pakai milik saya?
Pasti. Bot dibuat langsung di aplikasi Discord Developer milikmu, sehingga nama, avatar profil, bio, dan status sepenuhnya milik server kamu.
Bagaimana jika terjadi error atau perubahan dari Discord?
Kami sediakan masa garansi perbaikan bug dan pendampingan teknis. Jika Discord memperbarui library atau API-nya, kode bot akan kami sesuaikan agar tetap jalan normal.

Punya Ide Bot untuk Komunitasmu?

Ceritakan konsep servermu sekarang. Kami bantu rancang alur fitur dan bot yang pas, stabil, dan siap langsung dipakai komunitasmu.
